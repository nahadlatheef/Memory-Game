# Simon Says

A browser-based recreation of the classic electronic memory toy — watch the pattern, repeat it back, and see how far you can go before you slip up.

🔗 **Live demo:** https://nahadlatheef.github.io/Memory-Game/

## Features
- Classic 4-color pattern game loop with increasing difficulty
- Synthesized audio tones per color (Web Audio API — no sound files needed)
- Game-over state with level reached, plus a best score saved in your browser
- Full keyboard support (1–4 or Q/W/A/S) alongside click/tap
- Responsive layout, works on mobile and desktop
- Speeds up as you climb levels, like the original toy

## Built with
HTML, CSS, and vanilla JavaScript — no frameworks, no dependencies.

## Run locally
```bash
git clone https://github.com/nahadlatheef/Memory-Game.git
cd Memory-Game
# open index.html in your browser — that's it, no build step
```
